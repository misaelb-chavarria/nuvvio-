Nuvvio Marine Intelligence API Documentation

Complete reference guide for integrating programmatic access to Nuvvio's bathymetric layers, benthic habitat grids, and real-time hydrodynamic model streams into external enterprise software and GIS pipelines.

1. Authentication & Security

All requests to the Nuvvio Spatial API require secure token-based authentication via HTTP headers. Institutional and enterprise partners are issued unique API tokens tied to scoped security roles. Tokens must be transmitted in the Authorization header using the Bearer schema.

curl -X GET "https://api.nuvvio.online/v1/spatial/metadata?region=north_sea" \
  -H "Authorization: Bearer nuv_live_98374a58bc2910f" \
  -H "Accept: application/json"

2. Core Spatial Endpoints

Bathymetry Retrieval Grid

GET/v1/bathymetry/raster

Retrieves high-resolution depth grids derived from AI bathymetric inversion models for a specified bounding box (WGS 84 coordinate reference system / EPSG:4326).

# Query Parameters:
# - bbox: min_lon,min_lat,max_lon,max_lat (Required)
# - resolution: target resolution in meters per pixel [default: 10]
# - format: output format (geotiff, netcdf4, cog)

GET /v1/bathymetry/raster?bbox=4.2,52.1,4.8,52.8&resolution=10&format=cog

Benthic Habitat Segmentation

GET/v1/benthic/classification

Accesses classified semantic layers detailing seabed substrates (coral matrices, seagrass beds, sedimentary floors) evaluated via spectral mixture analysis.

3. Python Integration Example

For data scientists and researchers integrating Nuvvio pipelines directly into localized Python or Jupyter Notebook environments, standard geospatial libraries such as requests and rasterio can be utilized to stream Cloud Optimized GeoTIFFs (COGs) directly from our servers.

import requests
import rasterio
from rasterio.plot import show

API_KEY = "nuv_live_98374a58bc2910f"
url = "https://api.nuvvio.online/v1/bathymetry/raster"

params = {
  "bbox": "4.2,52.1,4.8,52.8",
  "format": "cog"
}
headers = {"Authorization": f"Bearer {API_KEY}"}

response = requests.get(url, params=params, headers=headers)
if response.status_code == 200:
  print("Spatial tile retrieved successfully.")

4. OGC Web Services & Standards

To ensure total interoperability with traditional Geographic Information Systems (such as QGIS, ArcGIS Pro, and open-source spatial data stacks), Nuvvio fully supports Open Geospatial Consortium (OGC) standard protocols:

  • WMS (Web Map Service): For dynamic raster rendering and visualization of depth layers.
  • WFS (Web Feature Service): For vector-based boundary layers, survey tracks, and infrastructure corridors.
  • WCS (Web Coverage Service): For direct multi-dimensional grid data extraction.
